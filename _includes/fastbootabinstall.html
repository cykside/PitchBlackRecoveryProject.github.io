Fastboot Install (A/B)

Caution: Do not use `fastboot flash recovery` on A/B devices unless instructed. Always boot first.

  1. Reboot to bootloader:

    adb reboot bootloader

  2. Temporarily boot PBRP:

    fastboot boot pbrp.img

  3. Once PBRP boots, copy the PBRP zip to device.

  4. Go to Install > Select Zip > Swipe to Flash.

    This will automatically patch both slots.
